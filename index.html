TIMEFRAME

A random photo appears from the internet. Guess the year it was taken.

How it works: each round a real photograph is pulled at random from Wikimedia Commons. Slide to the year you think it was taken and lock it in.
Scoring: exact year = 1000 pts · otherwise 500 − 5 pts per year off (0 at 100+ years off).
Hints: century −100 pts, decade −150 more.
Online: the host creates a room, everyone else joins with the code from any device. All players guess the same photo simultaneously within 45 seconds — peer-to-peer via WebRTC, no server needed.
